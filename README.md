AとBは保存データ・キャッシュ・Service Worker を分けています。Bを初めて開くと、Aの記録と山行をコピーします(Aのデータは変わりません)。

### B版の追加機能(`b/`)
- **ハンターマップの重ね表示**: 県の鳥獣保護区等位置図(JPG)を取り込み、上下2画面で同じ場所を十字に合わせる(3点以上)と地図に重なる。4点以上で誤差(m)を表示。透明度を変えられる
- **区域の登録**: 鳥獣保護区・特別保護地区・休猟区・銃猟禁止区域・わな猟禁止区域を、地図をタップしてなぞって登録。GeoJSONで仲間と共有できる
- **警告**: 現在地が区域に入ると赤い帯と振動、150m以内に近づくと黄色い帯。禁止区域にわなを置こうとすると警告
- **熊本県の猟期**: 一般 11/15〜2/15、イノシシ・シカ 11/1〜3/15(令和8年度)
- 区域の判定は補助機能。元の地図が10万分の1のため、境界付近は現地の標識と公式マップで確認すること

## A版(段階1: 地図・GPS・オフライン地図)

狩猟用の地図アプリ。スマホのホーム画面に追加して使う PWA として作っています。

## できること

- **地図**: 国土地理院の地理院タイル(標準地図/淡色地図/航空写真)と、陰影起伏の重ね表示
- **GPS**: 現在地と精度の円、進行方向、追従表示
- **軌跡の記録**: 5mごとに記録します。標高は地理院の10mメッシュ(DEM)から取るので、GPSの高度より正確です。距離・登り・経過時間を表示し、GPXで書き出せます
- **オフライン地図**: 画面に映る範囲を、細かさ(ズーム14〜17)を選んで端末に保存します。保存した範囲は圏外でも、地図と標高の両方が使えます。一度見た地図も自動で最大3000枚まで残ります
- **記録**: くくり罠・箱罠・足跡・糞・ヌタ場・獣道・捕獲を地点つきで残せます。＋ボタンか地図の長押しで記録します
- **罠の見回り**: 確認が古い順に並びます。24時間以上確認していない罠は赤い輪で目立たせます。現在地からの方角と距離も出ます
- **銃猟可能時間**: 現在地の日の出〜日没、日没までの残り時間、猟期の残り日数を表示します
- **書き出し**: 記録と軌跡を GeoJSON で書き出せます(段階2のハンターマップ照合で使います)

データはすべて端末の中に保存され、外部には送信しません。

## 動かし方

GPS とオフライン保存は **https** でしか動きません(パソコンの `localhost` は例外)。

### パソコンで試す
```bash
cd ryouya-note
python3 -m http.server 8080
# ブラウザで http://localhost:8080
```

### スマホで使う(GitHub Pages の例)
1. GitHub で新しいリポジトリを作り、このフォルダの中身を全部アップロードする
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存する
3. 数分後に出る `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開く
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「アプリをインストール」
5. 初回に位置情報の許可を求められたら「許可」を選ぶ

Netlify Drop(https://app.netlify.com/drop)にフォルダをドラッグするだけでも公開できます。

## 山に入る前に

1. 電波のある場所で、猟場が画面に入るように地図を合わせる
2. 「地図保存」タブで細かさを選び、「この範囲を保存」を押す(15〜16がおすすめ)
3. 機内モードにして、地図と標高が出るか確かめる

## 既知の制限(ブラウザ版の限界)

- **iPhoneは画面を消すとGPSが止まります。** 記録中は画面を点けたままにしてください(対応端末では自動で画面が消えないようにしています)。裏で記録し続けるには、段階3のアプリ化が必要です
- 端末の空き容量が少ないと、ブラウザが保存した地図を消すことがあります。保存時に永続化を要求していますが、許可されるかはブラウザによります
- 猟期は一般的な 11/15〜2/15 で計算しています。都道府県の延長猟期や区域規制は、県の告示で確認してください

## 地図データの出典

国土地理院「地理院タイル」(標準地図・淡色地図・全国最新写真(シームレス)・陰影起伏図・標高タイル)
https://maps.gsi.go.jp/development/ichiran.html
※ 地理院への負荷を抑えるため、1回の保存は6000枚まで、同時取得は4本までにしています。

## ファイル構成

```
index.html            画面
css/style.css         見た目
js/app.js             画面の動き(地図・GPS・記録・パネル)
js/geo.js             地理院タイルの定義、距離・方位の計算
js/dem.js             標高タイルから標高を読む
js/offline.js         範囲を指定した地図の保存
js/sun.js             日の出・日没、猟期
js/store.js           端末内の保存
sw.js                 オフライン対応(Service Worker)
manifest.webmanifest  ホーム画面用の設定
```
