# 猟野ノート

熊本県の猟場向けの、狩猟用の地図アプリ。スマホのホーム画面に追加して使う PWA です。

**https://ontakesan.github.io/ryouya-note/**

## できること

- **地図**: 国土地理院の地理院タイル(標準地図/淡色地図/航空写真)と陰影起伏の重ね表示
- **GPS**: 現在地と精度の円、進行方向、追従表示
- **軌跡の記録**: 5mごとに記録。標高は地理院の10mメッシュ(DEM)から取るので、GPSの高度より正確。距離・登り・経過時間を表示し、GPXで書き出せる
- **オフライン地図**: 画面に映る範囲を、細かさ(ズーム14〜17)を選んで端末に保存。圏外でも地図と標高が使える。一度見た地図も自動で最大3000枚まで残る
- **スタンプ**: くくり罠・箱罠・足跡・糞・ヌタ場・獣道・捕獲を、上の列から選んで地図をタップするだけで記録。＋ボタンでメモつき記録
- **罠の見回り**: 確認が古い順に並ぶ。24時間以上確認していない罠は赤い輪で目立たせる。現在地からの方角と距離も出る
- **ハンターマップの重ね表示**: 熊本県の鳥獣保護区等位置図(JPG)を取り込むと、**自動で位置を合わせて**地図に重なる(下記)。透明度の変更・表示/非表示ができる
- **区域の登録と警告**: 鳥獣保護区・特別保護地区・休猟区・銃猟禁止区域・わな猟禁止区域を、地図をなぞって登録。現在地が区域に入ると赤い帯と振動、150m以内に近づくと黄色い帯。禁止区域にわなを置こうとすると警告。GeoJSONで仲間と共有できる
- **猟期と銃猟可能時間**: 熊本県の猟期(一般 11/15〜2/15、イノシシ・シカ 11/1〜3/15、令和8年度)、現在地の日の出〜日没と日没までの残り時間
- **書き出し**: 記録と軌跡を GeoJSON で書き出せる

データはすべて端末の中に保存され、外部には送信しません。

## ハンターマップの自動位置合わせ

県の地図には標準地域メッシュ(5倍メッシュ: 経度3.75分×緯度2.5分)の格子線が引かれ、マスごとに番号が振られています。格子線はちょうどその緯度経度の線なので、令和7年度版の全7ページについて画像中の格子線の位置を検出し、番号と照らし合わせて位置合わせデータを作りました(`js/kumamoto-sheets.js`、1ページ72〜90交点、誤差 平均9〜18m)。

- 県のページの画像そのものなら、SHA-256 で照合して即座に重なる
- 別のファイル(新しい年度版など)は、どのページかを1回選ぶと、画像から格子線を探し直して合わせる
- 熊本県以外の地図は、2画面で同じ場所を十字に合わせる手動の位置合わせも使える

画像は熊本県の著作物のため、このリポジトリには含めていません。利用者が県のページから保存して取り込む方式です。

**区域の判定は補助機能です。** 元の地図が10万分の1のため、境界には数十mのずれがあります。境界付近では現地の標識と公式マップで確認してください。

## 動かし方

GPS とオフライン保存は **https** でしか動きません(パソコンの `localhost` は例外)。

```bash
python3 -m http.server 8080   # http://localhost:8080
```

GitHub Pages(Settings → Pages → `main` / root)で公開しています。スマホでは iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「アプリをインストール」。

## 既知の制限

- iPhone は画面を消すと GPS が止まります。記録中は画面を点けたままに(対応端末では自動で画面が消えないようにしています)。裏で記録し続けるにはアプリ化が必要です
- 端末の空き容量が少ないと、ブラウザが保存した地図を消すことがあります

## ファイル構成

```
index.html               画面
css/style.css            見た目
js/app.js                画面の動き(地図・GPS・記録・区域・パネル)
js/hmap.js               ハンターマップの重ね表示、手動の位置合わせ、区域の判定
js/kumamoto-sheets.js    熊本県ハンターマップ7ページの自動位置合わせデータ
js/seasons.js            猟期(熊本県)
js/geo.js                地理院タイルの定義、距離・方位
js/dem.js                標高タイルから標高を読む
js/offline.js            範囲を指定した地図の保存
js/sun.js                日の出・日没
js/store.js / js/idb.js  端末内の保存
sw.js                    オフライン対応(Service Worker)
b/ , ab.html             旧URLからの転送と、旧B版の後片付け
```

保存キーの頭(`ryouyaB:`)や地図キャッシュ名(`b-tiles-*`)はB版の名残ですが、端末のデータを引き継ぐためにそのままにしています。

## 地図データの出典

- 国土地理院「地理院タイル」(標準地図・淡色地図・全国最新写真(シームレス)・陰影起伏図・標高タイル) https://maps.gsi.go.jp/development/ichiran.html
- 熊本県「鳥獣保護区等位置図」 https://www.pref.kumamoto.jp/soshiki/52/249903.html
- 熊本県 狩猟期間 https://www.pref.kumamoto.jp/soshiki/52/277773.html
